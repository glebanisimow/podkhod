# Медиа упражнений

Правило: только источники с явной лицензией, разрешающей встраивание. Коммерческие сайты и приложения
не скачиваются и не парсятся.

## Источники

| Источник | Лицензия | Решение |
|---|---|---|
| free-exercise-db (github.com/yuhonas/free-exercise-db), коммит `f00c92c7` | Unlicense (общественное достояние), по 2 JPG-кадра на упражнение | Используется: из 2 кадров собирается зацикленная анимация |
| wger (wger.de) | Creative Commons, у каждой записи своя; атрибуция, возможен share-alike | Не используется: хватило free-exercise-db, а пописьменная проверка лицензий дороже |
| ExerciseDB и наборы GIF на GitHub | Коммерческие условия, медиа третьих лиц | Не используются |
| Свои файлы пользователя | Ответственность пользователя (например, купленные паки) | Импорт папки через системный выбор файлов |

Оговорка о происхождении. free-exercise-db объявляет Unlicense и пишет, что данные пересобраны из
`wrkout/exercises.json`; откуда изначально взяты фотографии, в репозитории не описано. Для личной сборки
этого достаточно. Перед публикацией в магазине приложений происхождение кадров нужно перепроверить или
заменить кадры своими.

## Покрытие (catalogVersion 2)

- 87 из 90 упражнений (97 %) имеют анимацию, 79 уникальных файлов, 6,3 МБ в APK.
- 60 — `exact` (то же движение). 27 — `similar` (близкое движение или другой снаряд, например гиря вместо
  гантели); на экране у них значок «≈» и подпись «Похожее движение».
- Без анимации: `kettlebell_deadlift`, `band_curl`, `kettlebell_rack_carry`. Вместо анимации на странице
  упражнения показываются первые три тезиса техники, в миниатюре — «Без анимации».
- Тексты техники написаны для этого приложения, у всех записей `reviewed: false`.

## Конвейер `tools/build_media`

```powershell
pip install "Pillow>=10"
python tools/build_media/build_media.py            # клонирует free-exercise-db на закреплённом коммите
python tools/build_media/build_media.py --source <путь к локальной копии>
```

- `mapping.json` — соответствие `id упражнения → папка free-exercise-db` и тип совпадения `exact/similar`.
- Анимированный WebP: ≤ 360 px по большей стороне, кадр 84 мс (≤ 12 fps), удержание позы 900 мс,
  плавный переход 5 кадров, качество подбирается под цель ≤ 150 КБ.
- Выход: `app/src/main/assets/media/*.webp` и `assets/media_manifest.json` (файл, источник, `sourceId`,
  тип совпадения, лицензия, автор, sha256). Из манифеста заполняется «О приложении → Лицензии анимаций».

## Воспроизведение

- Анимация играет только на видимой странице упражнения и только пока приложение на экране.
- Выключатель «Анимации упражнений» в настройках и системное «Без анимации» (масштаб анимаций 0) дают
  статичный первый кадр.
- Изображение рисуется в своём графическом слое, поэтому смена кадра не перерисовывает остальную страницу.

## Свои файлы

«Настройки → Добавить свои анимации», выбрать папку. Файл `<id упражнения>.gif` или `.webp` (например,
`barbell_back_squat.webp`) перекрывает встроенный. Файлы копируются в память приложения; принимаются только
известные `id`, размер до 5 МБ и настоящая сигнатура GIF/WebP. Остальные пропускаются со списком причин.
